Python Command Line Recipe app

Project Overview

A Python-based command-line application that serves as the foundation for the Django web version of the Recipe app. This project highlights Python fundamentals, object-oriented programming, and basic database interaction.
Key Features:

  • Create, view, and modify recipes stored in a locally hosted MySQL database.
  • Search recipes by ingredients to quickly find matching dishes.
  • Automatically calculate the difficulty of a recipe based on its cooking time and number of ingredients.
  • Display detailed recipe information such as ingredients, cooking time, and difficulty.

This project demonstrates core Python scripting skills, efficient use of data structures, and database connectivity—laying the groundwork for building the more complex web application with Django.

Technologies Used

  • Python 3.13
  • Object-Oriented Programming (OOP) in Python
  • Command-line interface (CLI) development
  • IPython – Enhanced interactive Python shell used during development for testing and debugging.
  • bcrypt – Python library for securely hashing and verifying passwords.
  • MySQL for local database storage
  • SQLAlchemy ORM for database interactions
  • Python standard libraries for file handling, data structures, and exception handling
  • Command-Line Interface (CLI) – Text-based user interface with numbered options for simple, user-friendly navigation.
  • Virtual environments and pip for package management
  • Git & GitHub for version control and repository hosting

Objective

To build a Python-based command-line Recipe app that demonstrates core programming skills, including object-oriented design, data handling, and database interaction. The project allows users to create, read, update, and search recipes, providing a solid foundation for developing a full-stack web application in Django.

The Experience

Working entirely in the command line gave me a deeper understanding of Python’s development workflow, building each feature step by step, and laying the foundation for the Django recipe app. This project let me experience virtual environments, terminal commands, and Python’s object-oriented approach to variables—different from JavaScript’s loosely typed variables.

The process included:

  • Creating and manage virtual environments
  • Using data types and methods to execute Python commands that store recipes containing their own internal data
  • Building a script that uses if-elif-else statements, for loops, and functions to take recipes from the user then displaying them
  • Creating a Python script that takes recipes from the user and writes the data in a binary file, then another script that reads the binary file and lists the available ingredients
  • Setting up a MySQL database and connecting the scripts to it
  • Building an application that creates, reads, updates, and deletes recipes, as well as searches for them by a single ingredient
  • Using an Object Relational Mapper from SQLAlchemy to manage the contents of the database
  • Building a user-friendly menu for entering and searching for recipes and ingredients
